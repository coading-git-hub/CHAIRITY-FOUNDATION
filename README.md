# Charity Foundation Website

A modern, responsive charity foundation website built with HTML5, CSS3, and JavaScript.

## 🎯 Features

- **Fully Responsive Design** - Works seamlessly on all devices (desktop, tablet, mobile)
- **Modern UI/UX** - Clean, professional design with smooth animations
- **Cross-Browser Compatible** - Tested on Chrome, Firefox, Safari, Edge
- **SEO Optimized** - Proper meta tags, semantic HTML, and accessibility features
- **Fast Performance** - Optimized code, lazy loading, and minimal dependencies

## 📄 Pages Included

1. **Home** - Hero carousel, featured causes, news & events, staff section, testimonials
2. **About Us** - HTML elements showcase (columns, buttons, tables, accordions)
3. **Contact Us** - Contact form, location cards, Google Maps integration
4. **Causes** - Single cause detail, features, comments section, sidebar
5. **Events** - Event details, countdown timer, map, sidebar
6. **Staff** - Team member cards with social links
7. **404 Error** - Custom error page with search and quick links

## 🚀 Technologies Used

- **HTML5** - Semantic markup
- **CSS3** - CSS Variables, Flexbox, Grid, Animations
- **JavaScript** - ES6+ (vanilla, no frameworks)
- **Bootstrap 5.2.3** - Grid system and components
- **Font Awesome 6.6.0** - Icons

## 🎨 Customization

### Colors
Edit CSS variables in `style.css`:
```css
:root {
  --primary-color: #fa6f1c;      /* Main orange */
  --primary-dark: #ce520a;       /* Darker orange */
  --secondary-color: #3a559f;    /* Blue */
  --accent-color: #82b440;       /* Green */
  --text-dark: #27262c;          /* Dark text */
  --text-light: #75737f;         /* Light text */
}
```

### Fonts
The site uses system fonts for performance. To change:
```css
:root {
  --font-primary: 'Your Font', sans-serif;
}
```
